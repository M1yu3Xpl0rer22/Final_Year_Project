Authentication Failures

HIGH SEVERITY

Identification and Authentication Failures occur when applications improperly verify user identities or manage sessions. This allows attackers to compromise passwords, keys, or session tokens to assume the identities of other users, temporarily or permanently.

🔍 What Does It Look Like?

Allowing weak passwords:

password: "123456"

Or leaving session tokens exposed in URLs:

app.com/dashboard?session_id=abc1234

🚨 Why It's Dangerous

  • Account takeover (ATO)
  • Identity theft
  • Access to sensitive user data
  • Reputational damage

✅ How to Prevent It

  • ✓ Implement Multi-Factor Authentication (MFA).
  • ✓ Don't allow weak or default passwords (use a strength meter).
  • ✓ Implement rate limiting to prevent brute force attacks.
  • ✓ Use secure, randomized session IDs and invalidate them on logout.

💡 Secure Pattern

❌ Insecure:

if(user && pass) login();

✅ Secure:

if(check(user, hash) && mfaOK()) 
  createSession();
