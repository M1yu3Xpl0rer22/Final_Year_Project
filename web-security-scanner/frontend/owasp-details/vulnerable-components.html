Vulnerable Components

MEDIUM SEVERITY

Vulnerable and Outdated Components occur when applications use libraries, frameworks, or software components with known security flaws. These components often have publicly disclosed vulnerabilities that attackers can exploit to compromise your application.

🔍 What Does It Look Like?

Your application might be using an old version of a library:

"dependencies": {
  "jquery": "1.8.3" // Known XSS flaws
}

Attackers use automated tools to scan for these specific versions and launch pre-made exploits.

🚨 Why It's Dangerous

  • Publicly known exploits are easy to use
  • Can lead to full system compromise (RCE)
  • Difficult to track without an inventory
  • Affects the entire supply chain

✅ How to Prevent It

  • ✓ Maintain a Software Bill of Materials (SBOM).
  • ✓ Regularly update all dependencies and libraries.
  • ✓ Remove unused dependencies, features, and files.
  • ✓ Use automated tools to scan for vulnerabilities in your build pipeline.

💡 Tools to Use

Automate your security checks with these standard tools:

npm audit         # For Node.js
mvn dependency:check # For Java
pip audit         # For Python
