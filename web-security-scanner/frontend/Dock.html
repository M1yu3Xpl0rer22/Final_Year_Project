ShieldByte Docs

Everything you need to know about using the ShieldByte vulnerability scanner to secure your web applications.

1. Getting Started

Navigate to the Scan Page, enter a valid website URL, and click Start Scan. Our engine will automatically analyze the input against OWASP Top 10 vulnerabilities.

2. CLI Usage (Advanced)

For automated testing in CI/CD pipelines, use our CLI tool:

$ shieldbyte --scan https://yourdomain.com --output report.html

3. Understanding Reports

The scan report provides detailed insights into found vulnerabilities:

⚠️

Risk Level

Critical, High, Medium, Low severity classification.

🎯

Affected Area

Specific endpoints or parameters.

🛡️

Fix Guidance

Step-by-step remediation instructions.

4. Technology Stack

ShieldByte leverages industry-standard open-source tools including OWASP ZAP and sqlmap, combined with our proprietary AI-driven analysis engine to reduce false positives.

5. Support

Need help? Contact our security research team at support@shieldbyte.io.
