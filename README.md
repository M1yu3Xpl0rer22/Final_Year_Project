## 📖 Overview

**Web Security Risk Detection Using Open Source Tools** is a web security assessment project developed to identify security vulnerabilities in web applications using multiple open-source penetration testing tools. The system automates vulnerability scanning, analyzes security risks, and generates reports based on the **OWASP Top 10** security standards.

This project demonstrates how organizations can proactively identify and mitigate security threats before they can be exploited by attackers.

---

## ✨ Features

- 🔍 Automated vulnerability scanning
- 🛡️ OWASP Top 10 based security assessment
- 💉 SQL Injection detection
- ⚠️ Cross-Site Scripting (XSS) detection
- 🌐 Web server configuration analysis
- 📊 Vulnerability reporting
- 📈 Risk classification
- 🔒 Security recommendations
- ⚡ Fast and efficient scanning
- 📑 Detailed scan results

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/mayursapkale009/Final_Year_Project.git
```

### Navigate to the Project

```bash
cd Final_Year_Project
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Project

```bash
python app.py
```
